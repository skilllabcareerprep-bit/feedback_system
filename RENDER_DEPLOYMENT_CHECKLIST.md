## 🔧 Step-by-Step Deployment Process

### Step 1: Prepare Git Repository
```bash
# Initialize git if not done
git init

# Add all files
git add .

# Create commit
git commit -m "Prepare for Render deployment"

# Add remote to GitHub
git remote add origin https://github.com/YOUR_USERNAME/feedback-system.git

# Push to GitHub
git push -u origin main
```

**Checklist:**
- [ ] Repository is on GitHub
- [ ] All files are pushed
- [ ] .gitignore is working (.env is not in repo)
- [ ] requirements.txt is in root

---

### Step 2: Create Render Account
```
1. Go to https://render.com
2. Click "Get Started"
3. Sign up with GitHub account
4. Authorize Render to access GitHub
5. Done! No credit card needed
```

**Checklist:**
- [ ] Render account created
- [ ] GitHub account connected
- [ ] Can see your repositories

---

### Step 3: Deploy Web Service
```
In Render Dashboard:
1. Click "New +"
2. Select "Web Service"
3. Connect your GitHub account
4. Select "feedback-system" repository
5. Fill in deployment settings:
   Name: training-feedback-system
   Environment: Python 3
   Build Command: pip install -r requirements.txt && python training_feedback_system/manage.py collectstatic --no-input && python training_feedback_system/manage.py migrate
   Start Command: gunicorn training_feedback_system.wsgi:application
   Plan: Free
6. Click "Create Web Service"
```

**Checklist:**
- [ ] Web service created
- [ ] Build command is correct
- [ ] Start command is correct
- [ ] Using Free plan

---

### Step 4: Deploy PostgreSQL Database
```
In same Render Dashboard:
1. Click "New +"
2. Select "PostgreSQL"
3. Fill in:
   Name: training-feedback-db
   Database: training_feedback
   User: postgres
   Region: Choose closest to you
   Plan: Free
4. Click "Create Database"
5. Copy the database connection string
```

**Checklist:**
- [ ] PostgreSQL database created
- [ ] Database name: training_feedback
- [ ] Copied connection string

---

### Step 5: Configure Environment Variables
```
In Web Service Settings → Environment:
Add these variables:

DEBUG=False
ALLOWED_HOSTS=training-feedback-system.onrender.com,localhost
SECRET_KEY=[generated by Render]
PYTHON_VERSION=3.12.0

DATABASE_URL=[paste from PostgreSQL service]
OPENAI_API_KEY=[your OpenAI key if you have one]
EMAIL_HOST_USER=[your email for notifications]
EMAIL_HOST_PASSWORD=[your email app password]
```

**Checklist:**
- [ ] All variables added
- [ ] DATABASE_URL is correct
- [ ] SECRET_KEY is set
- [ ] DEBUG=False
- [ ] PYTHON_VERSION=3.12.0

---

### Step 6: Wait for Deployment
```
Render will automatically:
1. Clone your GitHub repo
2. Install dependencies (pip install -r requirements.txt)
3. Collect static files
4. Run migrations
5. Start your app with Gunicorn

Timeline: 5-10 minutes

Watch the build logs for errors
```

**Checklist:**
- [ ] Build starts automatically
- [ ] No build errors
- [ ] Deployment completes
- [ ] Website shows "Live"

---

**Checklist:**

## 🚨 Troubleshooting

### Build Failed
**Error:** "Failed to install dependencies"
**Solution:**
- Check requirements.txt syntax
- Ensure all packages are compatible with Python 3.12
- Check for missing version pins

### 502 Bad Gateway
**Error:** Website shows 502 Bad Gateway
**Solution:**
- Check build logs for errors
- Verify Gunicorn is running
- Check environment variables are set

### Database Connection Error
**Error:** "OperationalError at /: FATAL: password authentication failed"
**Solution:**
- Verify DATABASE_URL in environment variables
- Make sure it matches PostgreSQL service URL
- Check database credentials

### Static Files Not Loading
**Error:** CSS/JavaScript return 404
**Solution:**
- Verify `python manage.py collectstatic` ran in build
- Check STATIC_ROOT and STATIC_URL are correct
- Verify WhiteNoise middleware is in settings

### Migrations Failed
**Error:** "django.db.utils.ProgrammingError"
**Solution:**
- Run migrations manually in Shell
- Drop and recreate database if needed
- Check migrations folder is complete
